# Security Invariant Ledger

Maps every Security-section **MUST** in [CONSTRAINTS.md](../CONSTRAINTS.md) (plus security-adjacent Observability MUSTs) to an **owning lane** and **pinning test or doc**. Constraint text stays in CONSTRAINTS — this file is the ownership index.

**Lamination:** each core lane pack lists ledger ids it owns under **Security pins**. Lanes run their pins as sensors during execute; no permanent SECURITY peer branch.

**Campaign mode:** temporary audit or hardening sprints may load multiple lane packs plus this ledger. See [README.md](./README.md#security-laminated-not-a-peer-branch).
