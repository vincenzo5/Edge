# Local production containerization — Phase 4 evidence
# Date: 2026-07-26

## Scope
Image-based promotion and rollback for container production: build revision-pinned
edge-app images, migrate, replace app-prod after Docker + healthz/readyz/Redis gates,
persist SHA/digest deploy state, prune retained images. No Phase 5 legacy retirement.

## Delivered
- scripts/local-prod.mts — deploy-revisions.json digest fields + status lines
- scripts/build-app-image.mts — readImageDigest, list/prune edge-app image retention
- scripts/deploy-local-prod-container.mts — deploy/rollback CLI composing build/migrate/start + health gate
- scripts/deploy-local-prod-container.sh — thin launcher
- scripts/deploy-local-prod-container.test.ts — CLI contract, state, prune, gate tests
- package.json — local:prod:container:deploy, local:prod:container:rollback
- .env.example — Phase 4 operator notes
- src/lib/observability/ARCHITECTURE.md — Phase 4 container deploy/rollback section

## Architecture review
Self-review Passed — container deploy reuses Phase 1–3 image/compose contracts and
legacy migration/health-gate modules; failed candidates stay unpromoted; rollback
restores previous immutable image + digest; status/logs omit secrets.
