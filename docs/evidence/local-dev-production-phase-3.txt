## Stop / uninstall idempotency
npm run local:prod:service:stop → local-prod.service=stop label=com.edge.local-prod
npm run local:prod:service:uninstall → local-prod.service=uninstalled label=com.edge.local-prod
second uninstall → exit=0 (idempotent)
