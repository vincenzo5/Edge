## Behavior

- Screenshots **Capture chart** opens `/journal/capture?token=…&tradeId=…` in a popup window.
- Seed clones active workspace cell config (or default cell) with trade symbol forced; stored in sessionStorage.
- Capture studio mounts live ChartCell with drawing rail; **Capture** saves screenshot + chart fork via `captureTradeChartFork`.
- Parent trade pop-up listens on `edge-journal-capture-v1` BroadcastChannel and reloads screenshot gallery on `captureDone`.
- Popup blocked shows inline error; Cancel publishes `captureCancelled` without persisting.

## App-level (manual)

1. Open journal trade detail → Screenshots → **Capture chart** → popup opens on trade symbol.
2. Add markup → **Capture** → popup closes → hero screenshot appears in trade detail.
3. Trade charts section gains new fork (Execution details).
4. Main workspace layout unchanged (isolated fork clone).
