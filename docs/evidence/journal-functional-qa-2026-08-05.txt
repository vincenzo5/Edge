### Cross-pack findings (priority)

1. **HIGH — Offline trade PATCH fallback broken:** When DB is down, `PATCH /api/me/journal/trades/:id` returns **400** (DB error as validation) instead of **503**. Client localStorage fallback only runs on 503 → rating, ignore-from-stats, setup/tags/notes do not persist. Screenshots tolerate 404 with local fallback (inconsistent).
2. **MEDIUM — Chart deep-link loses query:** Trade symbol `href` includes `journalTrade`+`goto`, but navigation to `/workspace` strips query; execution markers not confirmed.
3. **MEDIUM — Stop risk on closed short:** "Quantity is required to compute risk." when editing stop.
4. **INFO — Env:** `database_unavailable` throughout session; Sync/Import/read paths still usable via localStorage.

### Suggested next steps
- Fix PATCH offline path: map DB-unavailable to 503 (or broaden client fallback beyond 503).
- Preserve `journalTrade` (and related) query params across workspace redirect / overlay bootstrap.
- Re-run Packs C/D/E review-save + deep-link checks with Postgres up for full green.
