## Root cause A — Flex fill timestamps shifted -4h in production
edge-app-prod TZ=UTC.
parseFlexCsv.normalizeFillTime uses `new Date(y,m,d,h,mi,s)` (process local time).
IB Flex DateTime values are US/Eastern clock times (e.g. 20260624;093542 = 09:35:42 ET).
In UTC container they are stored as 09:35:42Z → UI shows 05:35 ET.
Evidence in edge_prod journal_fills:
  flex_csv total: 92
  flex fills with ET hour 5-6: 32
  flex fills exactly 05:30 ET: 13 (classic RTH open mis-labeled)
Live fills (IB API ISO+offset) are correct — LQDA exit 14:35 ET.

## Root cause B — rebuild wipes initial_stop, keeps planned risk
rebuildJournalTrades deletes+reinserts trades without initialStop column.
rebuildTrades() preserve list includes plannedRisk* but NOT initialStop.
Last ingest rebuild: 2026-08-06 ~18:00:35Z — all 14 trades recreated; all initial_stop NULL.
LQDA still has planned_risk_usd=1187.97 → UI R stays 2.02R even with empty stop field.
