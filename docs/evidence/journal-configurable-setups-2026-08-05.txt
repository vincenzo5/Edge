## Behavior
- Journal → Settings shows Setups editor (add/rename/reorder/delete/reset).
- Setup catalog stored in localStorage `edge.journal.setupValues.v1` and synced via userPreferences pack.
- Trade detail Setup dropdown and filter drawer read from catalog; orphan trade values remain selectable.
- Custom setup strings accepted on PATCH/API/adopt (no fixed enum drop).

## App-level
Deferred: Journal → Settings add setup → trade popup select → save → reload (manual on http://localhost:3003).
