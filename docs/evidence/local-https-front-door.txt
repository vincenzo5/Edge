## App-level — HTTPS front door (operator prerequisites)
Blocked in agent sandbox without sudo/password for /etc/hosts and port 443 bind.
Operator steps (documented in docs/ops/local-https.md):
1. sudo sh -c 'echo "127.0.0.1 edge.local" >> /etc/hosts'
2. mkcert -install
3. npm run local:https:install
4. cd ops/caddy && sudo caddy start --config Caddyfile --adapter caddyfile
5. curl -sf https://edge.local/healthz && curl -sf https://edge.local/readyz
6. Open https://edge.local/workspace in browser
